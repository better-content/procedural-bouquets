# Procedural Bouquets

Pack-owned procedural flower bouquet generator for Forge `1.20.1`.

## Common commands

```bash
./gradlew verifyFast
./gradlew verifyFull
./gradlew stageRuntimeJar
```

## Release artifact

Deploy the reobfuscated runtime jar from:

- `build/libs/procedural_bouquets-<version>.jar`
